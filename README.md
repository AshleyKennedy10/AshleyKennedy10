## Hi, I'm Ashley 👋

I'm a **Master of Data Science** student at the University of Pittsburgh (May 2027) with a background in mathematics and a strong interest in uncovering the stories hidden in data. I love working through complex problems and experimenting with different modeling approaches until the results make sense, both mathematically and intuitively.

Before grad school, I spent 2+ years in analytics roles in insurance and healthcare, where I automated reporting workflows and built forecasting models. Now I'm focused on **deep learning**, **LLM-powered agents**, and **predictive modeling**, building projects end to end in Python and R.

### 🚀 Featured Projects

**[Multi-Agent File Assistant](https://github.com/AshleyKennedy10/multi-agent-file-assistant)**
An orchestrator agent that delegates file search and summarization to specialist agents wrapped as tools, then compiles the results into written reports. Includes sandboxed file access and an offline test suite that runs without an API key.
`Python` `Langroid` `Gemini` `pytest`

**[AAPL Stock Price Forecasting with LSTM](https://github.com/AshleyKennedy10/aapl-lstm-stock-forecasting)**
A two-layer stacked LSTM in PyTorch that forecasts Apple's next-day closing price from 60-day sliding windows of historical market data.
`Python` `PyTorch` `scikit-learn` `yfinance`

**[Spotify Track Popularity Analysis](https://github.com/AshleyKennedy10/spotify-popularity-analysis)**
Exploratory analysis, PCA, hierarchical clustering, and regression vs. XGBoost on 30K+ tracks to find which audio features drive popularity.
`Python` `XGBoost` `scikit-learn` `GitHub Pages`
